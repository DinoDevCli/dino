usage: dino [-h] [--version] [--json] [--dev]
            {scan,bundle,flight,verify,map,capsule,proof} ...

Deterministic Proof for Python Decision Pipelines

positional arguments:
  {scan,bundle,flight,verify,map,capsule,proof}
    scan                Grammar and leakage scanning
    bundle              Run bundles and local stores
    flight              Canary flight summary
    verify              Attestation verification
    map                 Import graph mapping and planning
    capsule             Sealed execution capsules
    proof               Unique proof chain: capsule + scan + map

options:
  -h, --help            show this help message and exit
  --version             show program's version number and exit
  --json                Emit JSON envelopes (also accepted before the domain)
  --dev                 Developer Mode: relax EMPTY_SCAN_ROOTS (not for
                        production proofs)

Meta: dino version | packs | status | upgrade --pack proof --key KEY | issue-key --team NAME [--days N] | init-license. Global: --json for machine-readable envelopes. --dev relaxes EMPTY_SCAN_ROOTS (not for production proofs).

Optional features (Proof Pack)
  - CI compare gate

  - engine contract stability
  - team mode
  - extended doctor checks
  - upgrade keys
